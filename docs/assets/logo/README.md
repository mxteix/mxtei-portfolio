# mxtei mark — "Stack"

Three chevrons widening as they fall. All straight edges, no curves.
Geometry lives in a 120x160 design space; files are cropped tight to the art.

## Files
- mark-gradient.svg   ember -> gold vertical ramp (#FF4D0F / #FF9A12 / #FFD84A). Primary.
- mark-ember.svg      single colour #FF5A1F
- mark-cream.svg      single colour #F1ECE6, for charcoal backgrounds
- mark-charcoal.svg   single colour #0B0A09, for ember or light backgrounds
- favicon.svg         thickened arms; holds together at 16px. Do not use above 32px.
- lockup-cream.svg    mark + wordmark, cream on dark
- lockup-charcoal.svg mark + wordmark, charcoal on light

## Notes
- The gradient id is `mxteiEmber`. Rename it if you inline several copies on one page.
- Lockups set the wordmark as live `<text>` in Sora 600. Convert to outlines before
  shipping anywhere Sora is not loaded, or swap in your own text node.
- Minimum size for the three-chevron version is 20px tall; below that use favicon.svg.
- Clear space: half the mark's width on all sides.
